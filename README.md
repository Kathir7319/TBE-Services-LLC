# TBE Services LLC - Modern Multi-Page Website

A modern, high-performance, and mobile-responsive multi-page React application built for **TBE Services LLC**, featuring property maintenance and lawn care solutions in **Morrisville, NC**.

---

## 📋 Content Blueprint Implementation

### 1. Home Page (`/`)
- **Main Headline:** *Flawless Lawns. Pristine Properties. Year-Round Dependability.*
- **Sub-Headline:** *Professional property maintenance and landscaping solutions for commercial and residential spaces in Morrisville, NC.*
- **Features:** Dynamic hero with trust badges, quick-access callouts, interactive quote calculator, proof metrics, service overviews, and client testimonials.

### 2. Our Services (`/services`)
- **Commercial Property Maintenance:** Scalable contracts for corporate offices, retail hubs, and managed communities.
- **Residential Lawn Care:** Scheduled mowing, edging, shrub trimming, and seasonal mulch styling.
- **Interactive features:** Tabbed category filtering, scope breakdowns, seasonal care cycle, and contract inquiry triggers.

### 3. Contact & Estimates (`/estimates`)
- **Phone:** `(919) 500-9991` (Click-to-call direct routing on desktop and mobile)
- **Hours:** `Open 24/7` (Highlighted with live dispatch indicators)
- **Location:** Morrisville, NC (With full Research Triangle coverage)
- **Interactive features:** Dynamic Property Estimate Calculator, instant quote request form, 24/7 emergency hotline callouts, and FAQs.

### 4. Additional Pages
- **About Us (`/about`):** Company philosophy, 4 core standards of excellence, safety/insurance credentials, and Morrisville community roots.
- **Property Gallery (`/gallery`):** Filterable visual showcase of commercial office parks, retail grounds, residential turf striping, and mulch styling.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm (or pnpm / yarn)

### Development Server
Run the local dev server:
```bash
npm run dev
```

### Production Build
Build for production:
```bash
npm run build
```

Preview production build:
```bash
npm run preview
```

---

## 🛠️ Tech Stack
- **Framework:** [React 18](https://react.dev/)
- **Routing:** [React Router v6](https://reactrouter.com/) (Multi-page SPA with smooth scroll restoration)
- **Styling:** [Tailwind CSS v3](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Build Tool:** [Vite 6](https://vitejs.dev/)
